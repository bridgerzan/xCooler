# Changelog

All notable changes to xCooler are documented here.

## [1.0.0] - 2026-08-22

### Added

- Initial public release
- xCooler power plan creation
- Gaming-focused AC power settings
- Automatic previous power plan backup
- Automatic power plan restore
- Status menu
- Uninstall option
- Windows 10 and Windows 11 support
- Cyan terminal interface
- No background service
- No third-party dependencies
